TRANSFÈ

Logiciel de gestion des envois et des retraits d'argent d'une maison de transfert fictive, réalisé en Java avec une interface graphique.

Toutes les données utilisées dans ce projet sont fictives.

Principe
Un expéditeur dépose un montant dans une agence et reçoit un code de retrait. Le bénéficiaire retire la somme dans une autre agence en présentant ce code. Chaque agence tient une caisse en gourdes et en dollars.

Garantie centrale du logiciel : un code de retrait ne peut être payé qu'une seule fois, même si deux guichets le présentent au même instant.
